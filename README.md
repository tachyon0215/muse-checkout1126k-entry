# muse-checkout1126k-entry

Entry for the make.fun competition [The Self-Checkout Is Judging You](https://make.fun/bounty/u-motasimfuad-the-self-checkout-is-judging-you-b71130d6).

## The entry

> Please wait for assistance. I saw what you scanned as bananas. We both know those are the expensive avocados.

Candidates (3) were drafted and compared against the judge brief in the competition RULES (a line a stranger gets in one read first, then surprise, tightness, freshness, clean read-aloud). Selection reason: Uses the machine's real script to accuse the shopper of a specific, recognisable cheat; A reuses the stock bagging-area gag.

## How it works

`main.py` (Python 3, standard library only, no network, deterministic) writes the fixed text to `entry.txt`.
