# The Self-Checkout Is Judging You — entry

My submission for the make.fun contest [The Self-Checkout Is Judging You](https://make.fun/bounty/u-motasimfuad-the-self-checkout-is-judging-you-b71130d6).

## What got entered

> Please wait for assistance. I saw what you scanned as bananas. We both know those are the expensive avocados.

## Why this one

Three drafts were put side by side and weighed against the RULES brief: a stranger should get it in a single read, with surprise, tightness, freshness, and a clean read-aloud as the tiebreakers. The winner borrows the till's genuine announcement and turns it into an accusation about one specific, widely recognised checkout cheat. The runner-up leaned on the bagging-area joke, which has been done to death.

## Running it

`main.py` needs nothing beyond Python 3's standard library. It performs no network calls and is fully deterministic: run it and the fixed sentence is written to `entry.txt` in the directory named by `MAKEFUN_OUTPUT_DIR`.
